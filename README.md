# manuscript-citation-workflow

**引文核实**（CiteVerify）帮你把已经写好的稿件里，每一处还空着的引用核对清楚。

你在需要引用的地方打一个空的 `【】`。打开软件后，对着每一处去查找、筛选、插入英文期刊论文，最后导出两份东西：一份是已经填好引用的正文，一份是 References。

软件在本机窗口里使用（窗口标题是「引文核实」）。查找文献时需要能上网，走的是 [Crossref](https://www.crossref.org/)。

仓库：<https://github.com/Anastasia0521/manuscript-citation-workflow>

---

## 根据已经写好的引言和正文来核对

这个软件依据你已经写好的引言、正文来工作：你先完成稿件，再在需要引用的位置标上 `【】`，然后用它查找、筛选并核对这些位置该用哪篇文献。

**1. 从你已经写好的稿出发**  
你先写好引言和正文，保存为 PDF、Word、`.txt` 或 `.md`。打开软件后选中这份稿，它读取其中你标出的 `【】`。新建项目时需要这份稿件。

**2. 按你提供的主张、关键词或 DOI 查找**  
每一处都可以填写「这句话要支撑的主张」，或直接输入英文关键词、粘贴 DOI。软件用这些内容在 Crossref 上匹配已发表的期刊论文。能采用的是带 DOI 的英文期刊论文：需要有 DOI、类型为期刊论文、题名为英文，并排除 MDPI 期刊。同一篇（同一个 DOI）在一篇稿里最多用 2 次。

**3. 每一处都由你核对后再进入成稿**  
检索给出的是候选。你查看抽出的原句和这篇文献，再选择「保留」或「删除【】」。全部核对完成后，才能导出正文和 References。

**4. 用网页核实这篇文献**  
有 DOI 时会出现 **打开 DOI 核对**。点开后可在 DOI 页面查看原文信息，确认它支撑你那句话，再决定采用与否。

## 这个软件做什么

按实际使用顺序，它做四件事。

**1. 找出稿件里每一处需要引用的位置**  
你只写空的 `【】`，不用自己编号。软件按出现顺序自动编成第 1 处、第 2 处……列表里会显示成 `C001 【1】`。

**2. 查找文献**  
每一处都可以：

- 粘贴 DOI，点 **用 DOI 拉取**；或
- 输入英文关键词，点 **检索候选文献**，再点 **采用这篇**。

不内置某个学科的期刊名单，也不限制你做哪个领域。目标期刊只决定导出时括号和参考文献的排版样子。

**3. 筛选文献**  
能留下来的，必须是带 DOI 的英文期刊论文。下面这些会直接被拒绝，请换一篇：

- 没有 DOI
- 不是期刊论文
- 题名含中文
- MDPI 的期刊

同一篇文献（同一个 DOI）在一篇稿里最多用 2 次。

**4. 插入并导出**  
你确认采用的，导出会把 `【】` 换成 `(Author, Year)` 或 `（Author, Year）`，并写进 References。  
某一处不想引用了，选 **删除【】**：正文里留下空的 `【】`，不进参考文献。

导出得到两个文件（都在该篇稿的项目文件夹里）：

- `phase3-cited-paragraphs.md`：对照表 + 可粘贴的正文
- `phase4-references.md`：参考文献列表

## 稿件怎么准备

支持 PDF、Word（`.docx`）、`.txt`、`.md`。旧版 `.doc` 不行，请另存为 `.docx` 或 PDF。

每个要引用的位置写成空的 `【】`。不要写成 `【1-3】`，也不要自己填序号。括号里只有空格的 `【 】` 也可以。

稿件正文可以是中文或英文；要插入的文献必须是英文期刊论文。

Word 只读正文段落和表格，不读页眉、页脚、脚注。PDF 按整页文字读取，所以不要把 `【】` 写在页眉页脚里。

如果旧稿已经全部写成互不重复的 `【1】` `【2】`，软件会沿用。不要把空的 `【】` 和已编号的混在同一篇里。

从源码运行需要 Python 3.11 或更高。若你用的是已经打包好的 `CiteVerify.exe`，不必装 Python。

## 怎样打开

把仓库放到本机后，在仓库根目录打开终端。

Windows：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\citeverify.exe
```

也可以双击 `run.bat`。第一次会自动创建环境并安装，以后再点就直接打开。

macOS / Linux：

```bash
python -m venv .venv
.venv/bin/pip install -e .
.venv/bin/citeverify
```

窗口打不开时，加上 `--browser`，会用浏览器打开同一套界面：

```powershell
.\.venv\Scripts\citeverify.exe --browser
```

不要在命令行里传稿件路径，选文件在窗口里完成。

## 怎样使用

### 第一步：新建稿件

首页点 **新建稿件**，填标题、选目标期刊、点 **浏览** 选稿件，再点 **创建并提取【】**。

目标期刊四个选项，只影响排版：

| 你选的目标期刊 | 正文里的括号 | 参考文献的样子 |
|------|----------|-----------------|
| Journal of Environmental Management | `(Author, Year)` | 英文作者—年份，刊名缩写，带 DOI |
| 生态学报 | `（Author, Year）` | GB/T 7714 著者-出版年制 |
| GB/T 7714 著者-出版年制 | `（Author, Year）` | 同上 |
| 通用英文作者—年份 | `(Author, Year)` | 和 JEM 那种英文格式一样 |

抽不出 `【】` 时，首页会提示原因，不会生成空项目。常见原因：写成了 `【1-3】`、空括号和已编号混用、同一个号写了两次、括号里乱填、文件格式不对、全文没有 `【】`。

稿件和一份记录表会放在本机项目文件夹。默认位置在首页「项目存放在：」那一行，Windows 上一般是：

`C:\Users\<用户名>\AppData\Local\CiteVerify\CiteVerify\projects\`

可用 **更改存放位置** 改到别的盘。已有项目点 **打开**。第一次用不必点 **导入旧项目**。

### 第二步：给每一处找文献

进入稿件后有两个页签：**核查**、**导出**。先在核查里做。

左侧是每一处，例如 `C001 【1】`。点进去：

1. 看抽出的原句（软件会在原句里标上编好的号）。
2. 可以填「这句话要支撑的主张」，方便检索；不填也行。
3. 粘贴 DOI 点 **用 DOI 拉取**，或用英文词点 **检索候选文献**，再 **采用这篇**。检索最多给出 8 条。
4. 有链接时点 **打开 DOI 核对**，确认这篇真实、并且能支撑原句。
5. 选一个决定，需要的话写备注，点 **保存**。核对完这一处后，点 **锁定本条**（意思是：这里已经定了，可以一起导出）。

决定只有三个有用的选项：

- **保留**：用这篇。必须已经有 DOI。导出时插入作者和年份，并进入 References。
- **删除【】**：这处不引用了。导出时正文留下空的 `【】`。
- **更换文献**：还没想好，还不能导出。请改成「保留」或「删除【】」。

如果还没选决定就点「锁定本条」，软件会当成「保留」，因此也必须先有 DOI。

检索不到时，请改用英文关键词，或直接填 DOI。中文整句拿去搜，往往没有结果。

### 第三步：导出

先确认每一处都已经核对完。不想一处一处地点时，可在导出页点 **锁定已填条目**：已经有 DOI 的会按「保留」确认；选了「删除【】」的也会确认；选了「更换文献」或还没填 DOI 的会跳过。

点 **检查 DOI 预算** 可以先看：有没有同一篇用过两次以上、每一处是否还是一对一。

然后点 **导出正文和参考文献**。成功后，结果框里会给出文件路径。

还没核对完、还停在「更换文献」、该保留的没有 DOI、同一篇用了超过 2 次，都导不出。窗口会说明原因，不会随便写出一份错的成稿。

相邻几处引用会合成一个括号，中间用分号隔开。同一作者、同一年、但是两篇不同的文献，年份后会加 `a`、`b`。

页底有一句说明：「导出文件写在本项目文件夹里，整夹拷走即可换电脑继续。」

## 项目文件夹里有什么

```
<项目名>/
  manuscript.pdf          # 或 .docx / .txt / .md，你的原稿副本
  citation-registry.json  # 每一处【】找到了哪篇文献
  phase3-cited-paragraphs.md   # 导出后才有：对照表 + 可粘贴正文
  phase4-references.md         # 导出后才有：参考文献
```

标题重名时不会覆盖，会变成 `原名-2`、`原名-3`。

换电脑继续做同一篇：拷走整个项目文件夹。软件要另外拷（见下）。到新电脑后首页点 **打开**，改完再导出即可。右上角 **全部稿件** 可以回到首页。

## 拷到另一台 Windows 电脑

在仓库根目录执行：

```powershell
.\scripts\build_windows.ps1
```

完成后，把整个 `dist\CiteVerify` 文件夹拷走（里面要有 `CiteVerify.exe` 和 `_internal`），双击 `CiteVerify.exe`。不要只拷一个 exe。

稿件不在这个文件夹里，仍在前面说的项目存放位置。

## 常见问题

**检索没有结果？**  
用英文关键词，或直接填 DOI。

**抽出的句子有错字，或断得奇怪？**  
以原稿为准，导出前自己看一眼。软件取的是含有该处 `【】` 的那一句。

**以前做过的稿怎么接着改？**  
首页点 **打开**，改完再导出。
