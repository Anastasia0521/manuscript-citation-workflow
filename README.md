# manuscript-citation-workflow

**倒插文献**：论文初稿已经写好，但参考文献还没逐条落实时，用这个本机软件来补。

你在稿件里需要引用的位置先打一个空的 `【】`。软件找出每一处 `【】`，帮你检索或核对英文期刊论文，再导出两份文件：一份是已经换成 `(Author, Year)` 的正文，一份是 References。

窗口标题是「倒插文献」。检索和用 DOI 拉取文献需要能访问 [Crossref](https://www.crossref.org/)。

仓库：<https://github.com/Anastasia0521/manuscript-citation-workflow>

---

## 开始前准备什么

**1. 稿件**

支持 PDF、Word（`.docx`）、`.txt`、`.md`。不支持旧版 `.doc`（请另存为 `.docx` 或 PDF）。

每个要插文献的位置写成空的 `【】`。不要自己在括号里填 `1`、`2`，也不要写成 `【1-3】`。  
软件会按稿件里出现的先后顺序，自动编成 `【1】`、`【2】`、`【3】`。核查列表里看到的 `C001 【1】`，就是软件编的号。  
`【 】`（中间只有空格）也当成空占位。

如果你拿到的旧稿里，已经全部写成互不重复的 `【1】`、`【2】`，软件会沿用这些号。不要把空的 `【】` 和已编号的 `【1】` 写在同一篇里，抽取会失败。

稿件**正文**可以是中文或英文。

**2. 文献从哪里来**

软件不内置某个学科的期刊库，也不限制研究领域。每一处 `【】` 对应的文献，由你粘贴 DOI，或用英文关键词在 Crossref 里检索。

只接受带 DOI 的英文期刊论文（Crossref 类型为 `journal-article`）。没有 DOI、不是期刊论文、题名含中文、或属于 MDPI 的，都不能点「保留」，请换一篇。

**3. 运行环境**

从源码运行需要 **Python 3.11 或更高**。  
如果已经有打包好的 `Daocha.exe`，不需要安装 Python。

不要先自建项目编号或文件夹。点「创建并提取【】」时，软件会按稿件标题生成项目目录。

## 安装和启动

先把仓库克隆到本机，在仓库根目录打开终端。

Windows：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\daocha.exe
```

macOS / Linux：

```bash
python -m venv .venv
.venv/bin/pip install -e .
.venv/bin/daocha
```

Windows 也可以双击仓库根目录的 `run.bat`。若还没有 `.venv`，它会创建虚拟环境、执行 `pip install -e .`，然后启动 `daocha`。已经有虚拟环境时，它只负责启动。`run.bat` 会把后面的参数原样传给程序，例如 `run.bat --browser`。

独立窗口打不开时，用浏览器打开同一套界面：

```powershell
.\.venv\Scripts\daocha.exe --browser
```

启动相关参数只有 `--browser`。`--help` 可查看说明。不要在命令行里传稿件路径；选文件在窗口里完成。

## 窗口里怎么用

### 首页

顶部标题是「倒插文献」，说明文字是「把带【】的稿件做成可核对、可导出的引文稿。」

| 按钮 | 作用 |
|------|------|
| **新建稿件** | 开始一篇新的倒插 |
| **导入旧项目** | 选择已有的 `citation-registry.json`，可选再选对应稿件 |
| **更改存放位置** | 把项目文件夹改到别的盘或网盘 |

当前路径显示为「项目存放在：…」。默认在本机用户数据目录，Windows 上一般是：

`C:\Users\<用户名>\AppData\Local\Daocha\Daocha\projects\`

还没有稿件时提示：「还没有稿件。先选一份带【】的 PDF 或 Word。」  
已有项目以卡片列出：标题、目标期刊、引文处数、阶段。点 **打开**。

### 新建稿件

对话框标题是「新建稿件」，填写三项：

| 字段 | 作用 |
|------|------|
| 稿件标题 | 窗口和列表里的显示名称；同时用来生成项目文件夹名 |
| 目标期刊 | **只决定正文括号和 References 的排版**，不限制能检索哪个领域 |
| 稿件文件 | 点 **浏览**，选择 PDF / `.docx` / `.txt` / `.md` |

点 **创建并提取【】**。软件会：

1. 把稿件复制进项目目录，文件名变为 `manuscript.pdf`（或对应的 `.docx` / `.txt` / `.md`）；
2. 找出全部空的 `【】`（若全文已是互不重复的 `【n】`，则沿用这些号），按出现顺序编号；
3. 生成 `citation-registry.json`（每一处 `【】` 的登记表）；
4. 进入该项目的核查页。

点 **取消** 只关闭对话框，不建项目。

目标期刊四个选项与排版的对应关系：

| 选项 | 正文括号 | References 体例 |
|------|----------|-----------------|
| Journal of Environmental Management | `(Author, Year)` | JEM：作者缩写、刊名缩写、卷(期)、页码、DOI |
| 生态学报 | `（Author, Year）` | GB/T 7714 著者-出版年制 |
| GB/T 7714 著者-出版年制 | `（Author, Year）` | 与上一行相同 |
| 通用英文作者—年份 | `(Author, Year)` | 与 JEM 相同的英文作者—年份 |

抽取失败时停在首页，用通知提示原因，**不会**留下半成品项目。失败常见原因：

- 写成了范围号，例如 `【1-3】`
- 同一篇里既有空的 `【】`，又有已编号的 `【n】`
- 已经自己编号时，同一个号用了两次
- 括号里既不是空的，也不是纯数字
- 文件不是 PDF / `.docx` / `.txt` / `.md`（包括旧版 `.doc`）
- 全文没有找到任何 `【】`

Word（`.docx`）只读正文段落和表格，不读页眉、页脚、脚注。  
PDF 按每一页的全文抽取。不要把 `【】` 写在页眉、页脚或页码旁，以免被当成引文位。

### 导入旧项目

对话框标题是「导入旧的倒插文献项目」。说明文字是：「会把 registry 和稿件复制进本机数据目录，不再依赖原来的盘符。」

1. 必选：旧的 `citation-registry.json`
2. 可选：稿件（旧路径找不到时再选；浏览支持 PDF / `.docx` / `.txt` / `.md`）

点 **导入**。第一次用这个软件，一般不需要这一步。  
若旧登记表里的决定是 `keep_engel_2008` 或 `split_feock_inline`，会改成「保留」（`keep`）。已经是「保留 / 删除【】 / 更换文献」的保持不变。

### 核查

进入项目后，顶栏是稿件标题，右侧 **全部稿件** 回到首页。顶栏下显示：期刊、引文位数量、已填 DOI、已锁定、存放路径。两个页签：**核查**、**导出**。

左侧每一处显示为 `C001 【1】`（序号由软件编写）、当前文献短名或「尚未填写文献」，以及角标 `pending` 或 `locked`。点进去后：

1. 查看抽出的原句。来源是稿件里含该处 `【】` 的那一句；中英文都能断句，英文单词之间的空格会保留。界面里的原句会带上软件编好的 `【n】`。
2. 填写「这句话要支撑的主张」（可选）。输入框失焦时保存。下面的检索框会预填这项内容。
3. 用下面任一方式指定文献：
   - 粘贴 DOI，点 **用 DOI 拉取**。软件向 Crossref 补全题名、作者、刊名、卷期页。若不是 `journal-article`、没有 DOI、题名含中文、或属于 MDPI，会提示错误，不会写入。
   - 在「按主张或关键词检索 Crossref」里输入**英文**关键词，点 **检索候选文献**，在结果里点 **采用这篇**。检索使用 Crossref 的 `query.bibliographic`，过滤为 `journal-article`，去掉没有 DOI、MDPI、以及题名含中文的记录，最多列出 8 条。没有可用结果时提示：「没有可用的英文期刊论文（MDPI 已过滤）。请改英文关键词，或直接填 DOI。」
4. 有 DOI 时出现链接 **打开 DOI 核对**。请在浏览器里确认该篇真实存在，并且确实支撑原句。
5. 选择「决定」，可填「备注」，点 **保存** 或 **锁定本条**。

「决定」只有这些选项：

| 界面选项 | 写入 `citation-registry.json` 的值 | 锁定 / 导出时怎么处理 |
|----------|-------------------|-------------|
| 未决定 | 空 | **保存**可以。点 **锁定本条** 时会当成「保留」，因此必须已经有 DOI。导出前不能仍是未决定 |
| 保留 | `keep` | 必须已有 DOI 才能锁定。导出时正文插入 `(Author, Year)` 或 `（Author, Year）`，该文献进入 References |
| 删除【】 | `delete_marker` | 可以没有 DOI 就锁定。导出时正文留下空的 `【】`，不进入 References |
| 更换文献 | `replace` | 表示本条还没完成。不能锁定，也不能导出；请改成「保留」或「删除【】」 |

导出页的 **锁定已填条目** 不会处理「更换文献」：有 DOI 且尚未选择决定的，会标成「保留」并锁定；已选「删除【】」的一并锁定；没有 DOI 的不锁。成功后通知为「已锁定所有已填条目」。

同一 DOI 在一篇稿里最多用 2 次（按 C001、C002… 的顺序计，「删除【】」的不计）。  
MDPI 一律拒绝，判断依据包括：Crossref 成员 1968、出版社名含 MDPI、DOI 前缀 `10.3390` / `10.1989` / `10.20944` / `10.32545` / `10.35995`，以及软件内置的 MDPI 刊名列表。

### 导出

导出前必须同时满足：

- 每一条的 `status` 都是 `locked`
- 决定只能是「保留」或「删除【】」
- 选「保留」的必须有 DOI
- 同一 DOI 不超过 2 次
- 登记表里每一个 `【n】` 仍然只对应一行

三个按钮：

| 按钮 | 作用 |
|------|------|
| 检查 DOI 预算 | 把检查结果写进「检查与导出结果」：同一 DOI 是否超过 2 次、【】是否一对一 |
| 锁定已填条目 | 见上一节 |
| 导出正文和参考文献 | 同时写出下面两个文件。成功时结果框显示写出路径 |

写出位置就是该项目文件夹（顶栏「存放：」后面的路径）：

- `phase3-cited-paragraphs.md`  
  对照表（完整书目，供你核对）+「段内引文版正文（可粘贴）」。`delete_marker` 处保留空的 `【】`。相邻多处引文会合成为一个括号，中间用分号加空格分隔。同作者、同年、但 DOI 不同时，年份后会加 `a` / `b`。
- `phase4-references.md`  
  核查摘要 + 按作者排序、按 DOI 去重的 References。只有「保留」且带 DOI 的文献进入列表。

导出未通过时（还有未锁定、仍是「更换文献」或未决定、缺 DOI、DOI 超次数、【】不是一对一），窗口里会显示原因，不会把错误列表写成上述两个文件。

页底说明：「导出文件写在本项目文件夹里，整夹拷走即可换电脑继续。」

## 项目文件夹里有什么

```
<项目名>/
  manuscript.pdf          # 或 .docx / .txt / .md，新建时从你的原稿复制而来
  citation-registry.json  # 每处【】的状态和文献
  phase3-cited-paragraphs.md   # 导出后才有
  phase4-references.md         # 导出后才有
```

标题和已有项目重名时不会覆盖，文件夹会变成 `原名-2`、`原名-3`。

换电脑继续做同一篇稿：拷整个项目文件夹。软件本身要另外拷贝（见下一节）。到新电脑后，首页点 **打开**，可在核查里改条目再重新导出。

## 做成可拷贝的 Windows 程序

在仓库根目录执行：

```powershell
.\scripts\build_windows.ps1
```

该脚本会：若没有 `.venv` 则创建；执行 `pip install -e ".[dev]"`（其中包含 PyInstaller）；再按仓库根目录的 `daocha.spec` 打包。完成后终端提示可执行文件在 `dist\Daocha\Daocha.exe`。

把 **整个** `dist\Daocha` 文件夹拷到另一台 Windows 电脑（必须同时包含 `Daocha.exe` 和 `_internal`），双击 `Daocha.exe`。不要只拷贝 exe。

稿件数据不在这个安装目录里，仍在上面的用户 `projects` 目录，或你在首页「更改存放位置」里改过的路径。

## 硬性规则

下面这些是软件会执行的检查，不是写作建议：

1. 每个空的 `【】` 对应登记表一行；软件按出现顺序编号。范围号、空【】与已编号混用、重复的【n】、括号里乱填内容，抽取时会失败。
2. 只接受带 DOI 的英文期刊论文。无 DOI、Crossref 类型不是 `journal-article`、题名含中文，都不能保留。
3. 禁止 MDPI。
4. 同一 DOI 最多出现 2 次。
5. 导出要求全部锁定，且每条只能是「保留」或「删除【】」。

## 常见问题

**检索没有结果？**  
用英文关键词，或直接填 DOI。把中文主张整段拿去检索，往往命中很差。MDPI、无 DOI、非期刊论文、题名含中文的记录不会出现在候选里。

**PDF 抽出的句子有错字，或断句看起来不对？**  
抽出后仍可在「这句话要支撑的主张」和导出正文里人工核对。正文来源是稿件里含该处【】的那一句。

**如何继续改已经做过的稿？**  
首页点 **打开**，或从项目页点 **全部稿件** 再打开对应项目，在核查里改条目后重新导出。

**标题和已有项目重名？**  
不会覆盖。文件夹会变成 `原名-2`、`原名-3`。
